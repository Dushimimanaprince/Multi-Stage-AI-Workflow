Stage 1: Conversational Chat Prompt Specification

Tool-Agnostic

The human prompts a Chat-based AI to extract formal requirements and generate a strict JSON contract.

prompts/stage1-chat-prompt.md 
You are a Principal Software Architect specializing in domain-driven microservice design.
Your task is to take natural language feature requirements and produce an unambiguous,
production-grade JSON service contract conforming to the MultiStageServiceContract schema.

Rules:
1. Output ONLY valid JSON enclosed inside ```json ... ``` blocks.
2. Define complete data entities with field types, required flags, constraints, and defaults.
3. Define RESTful endpoints with exact HTTP methods, paths, and status codes.
4. Include explicit Quality Gate Criteria (test coverage >= 90%, response latency < 100ms, security headers).

Stage 1 Output: Standardized Service Contract

Schema Validated

Generated contract stored at specs/service-contract.json consumed directly by Stage 2 IDE Assistant.

specs/service-contract.json 
{
  "serviceName": "workflow-task-engine",
  "version": "1.0.0",
  "description": "Collaborative Workflow & Task Management Engine microservice",
  "entities": {
    "Task": {
      "primaryKey": "id",
      "fields": {
        "title": { "type": "string", "required": true, "minLength": 3, "maxLength": 100 },
        "priority": { "type": "string", "enum": ["low", "medium", "high", "critical"] },
        "status": { "type": "string", "enum": ["backlog", "in_progress", "review", "completed"] }
      }
    }
  },
  "endpoints": [
    { "method": "GET", "path": "/api/v1/health", "expectedStatus": 200 },
    { "method": "GET", "path": "/api/v1/tasks", "expectedStatus": 200 },
    { "method": "POST", "path": "/api/v1/tasks", "expectedStatus": 201 },
    { "method": "PATCH", "path": "/api/v1/tasks/:id", "expectedStatus": 200 },
    { "method": "DELETE", "path": "/api/v1/tasks/:id", "expectedStatus": 204 }
  ],
  "qualityGateCriteria": {
    "minimumTestCoverage": 90,
    "maxResponseTimeMs": 100,
    "requiredSecurityHeaders": ["x-content-type-options", "x-frame-options", "x-xss-protection"]
  }
}

Stage 2: IDE AI Synthesis Prompt

IDE Contextual

Passed into VS Code Copilot Chat, Cursor Composer, or Antigravity IDE alongside the contract.

prompts/stage2-ide-prompt.md 
@workspace /specs/service-contract.json
Implement the complete, production-ready microservice defined in the service contract.

Architecture Requirements:
1. Clean Layered Architecture:
   - src/models/task.js (Entity validation, defaults, status lifecycle)
   - src/repositories/task-repository.js (Data access layer with seed dataset)
   - src/services/task-service.js (Domain business rules and state transition validation)
   - src/controllers/task-controller.js (HTTP route handlers and request/response mapping)
   - src/controllers/health-controller.js (Health and metrics endpoint)
   - src/middleware/security.js (Security headers & latency timing)
   - src/server.js (Native HTTP routing engine, zero external dependency risk)

2. Strict Contract Enforcement:
   - Match all HTTP methods, route paths, status codes (200, 201, 204, 400, 404, 500).
   - Inject required security headers on every response.
   - Record response time to satisfy the <100ms Quality Gate target.
